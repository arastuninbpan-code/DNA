# D.N.A. — Day & Night Assistant

Веб-приложение D.N.A. Corporation в чёрно-золотом стиле.

## Исходный код

Главный репозиторий проекта: https://github.com/arastuninbpan-code/DNA
Основная production-ветка: `main`.

- `index.html` — приложение: HTML, CSS, JavaScript и встроенные ресурсы.
- `netlify.toml` — настройки публикации статического приложения.
- `README.md` — описание проекта и порядок работы.

Основные разделы: Home, Finance, Habits, Planner, News.
Пользовательские данные веб-версии преимущественно хранятся в `localStorage` браузера; GitHub хранит исходный код, а не эти данные.

## Локальный запуск

Отдельная сборка и установка зависимостей не требуются.
Для проверки через локальный HTTP-сервер из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000.
Данные браузера привязаны к origin: локальный адрес и опубликованный сайт используют разные хранилища.

## Публикация в Netlify

Используем существующий проект `soft-cuchufli-21df94`; новый сайт создавать не требуется.

Параметры для подключения репозитория:
- репозиторий: `arastuninbpan-code/DNA`;
- production-ветка: `main`;
- каталог публикации: `.` (корень репозитория);
- команда сборки: пустая, сборка не нужна.

Параметры публикации заданы в `netlify.toml`.
Сам файл не подключает GitHub к Netlify: привязку существующего проекта и production-ветку необходимо настроить отдельно.
Автоматический deploy требуется проверить после подключения тестовым коммитом.

Документация: https://docs.netlify.com/build/configure-builds/overview/

## Порядок работы

1. Брать актуальный код из GitHub.
2. Перед серьёзным изменением интерфейса кратко описывать предлагаемое изменение и его цель.
3. Вносить изменения небольшими итерациями, сохраняя существующую функциональность и фирменный стиль.
4. Проверять затронутые сценарии на мобильном и desktop-размерах.
5. Сохранять каждую законченную задачу коммитом в GitHub.

После настройки непрерывной публикации целевой процесс:
`изменение приложения → commit в GitHub → main → автоматический deploy Netlify`.

Не переписывать приложение целиком без необходимости.

## Проверка автопубликации

Для проверки связи GitHub → Netlify можно изменить только этот README и сохранить коммит в `main`. Затем нужно убедиться, что Netlify автоматически опубликовал именно этот коммит; ручной запуск deploy не подтверждает автоматическую публикацию.
